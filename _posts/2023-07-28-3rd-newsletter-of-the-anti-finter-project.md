The 3rd newsletter of the Anti-FinTer project is now available. Anti-FinTer develops versatile artificial intelligence investigative technologies for revealing online cross-border financing activities of terrorism, within the EC Internal Security Fund. The newsletter presents the latest project activities and results, including the technologies of the HUA computer vision group, which serves as the project technical manager.
